Technology Stack & Architecture

Engineering specifications powering NetRoute Web.

Backend: Java 21 & Lightweight HTTP Server

Powered by JDK 21's built-in com.sun.net.httpserver.HttpServer configured with Java 21 Virtual Threads (Executors.newVirtualThreadPerTaskExecutor()) for ultra-lightweight, high-concurrency request handling without the footprint of heavy frameworks.

JSON serialization and deserialization are handled strictly by Google Gson 2.11.0, preserving complete separation between domain models and HTTP transport envelopes.

Algorithms: Shortest-Path & Discrete-Event Simulation

Dijkstra's Algorithm: Implemented in com.netroute.routing.DijkstraRouter using java.util.PriorityQueue as a binary min-heap over adjacency lists. Guarantees deterministic path selection using secondary tie-breaking on node IDs and link IDs.

Discrete-Event Engine: Time is tracked as a discrete integer tick counter in com.netroute.simulation.SimulationEngine. Links enforce FIFO packet queuing and capacity thresholds ($\max$ packets starting per tick). Failed links trigger dynamic Dijkstra rerouting from the packet's current vertex.

Database: MySQL & Atomic JDBC Transactions

Relational persistence in netroute_db using MySQL Connector/J 9.1.0. Unified save operations coordinate topology updates and simulation run metrics in a single atomic database transaction with explicit rollback on error.

Retention Policy: Historical simulation runs retain denormalized topology names with ON DELETE SET NULL, ensuring experiment analytics remain permanently accessible even after topologies are deleted.

Frontend: HTML5 Canvas & Vanilla JavaScript

Zero external JavaScript frameworks (no React, Vue, or Angular). High-DPI HTML5 Canvas visualizer renders equipment glyphs, glowing cyan active Dijkstra routes, dashed red failure states, and real-time in-flight packet movement particles.

Key Features

• Graph Representation: Models heterogeneous network vertices (Computers, Routers, Servers) and weighted edges with routing costs, simulated delays, and link capacities.

• Resilient Routing: Immediate detection of link severance with real-time recalculation of alternative routes from the packet's current location.

• Zero-Framework Web Migration: Complete transformation of the original Java Swing desktop interface to a modern browser-based web dashboard while retaining 100% of existing Java business logic.
